# Project Remzo

Jednostavan Node.js API napravljen pomoću Express-a.

## Zahtevi

- Node.js 18 ili noviji
- npm

## Pokretanje

```bash
npm install
npm run dev
```

Server je dostupan na `http://localhost:3000`.

- `GET /` vraća pozdravnu poruku.
- `GET /health` vraća status servera.

Za produkcioni način rada koristi `npm start`.
